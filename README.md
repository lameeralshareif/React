# Paradise Nursery

Paradise Nursery is a React web application for browsing indoor plants, aromatic herbs, and medicinal plants, adding items to a shopping cart, and adjusting quantities before checkout.

## Features
- Landing page with company introduction and a **Get Started** button
- Categorized plant catalog with **Add to Cart** state updates
- Shopping cart page with quantity controls, item removal, total cost calculation, and **Continue Shopping** navigation

## Getting Started
```bash
npm install
npm run dev
